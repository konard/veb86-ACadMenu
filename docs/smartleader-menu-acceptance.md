# Приёмка меню ACadSmartLeader

[ТЗ](https://raw.githubusercontent.com/konard/veb86-ACadSmartLeader/25c0ed4498a18d4a940ee9626ff33be85bb1d211/docs/TZ-autocad-menu.md)
 · [Задача #5](https://github.com/veb86/ACadMenu/issues/5)

CI собирает три DLL с соответствующими Autodesk SDK. Тесты проверяют команды кнопок и
контекстного пункта, маршруты пакета, предварительное выделение, отказ при занятой командной
строке, снятие старой группы и повторную регистрацию. Windows CI проверяет состав архива и
установку в изолированный `%APPDATA%`.

Для пунктов 2–5 требуется интерактивный сеанс AutoCAD. Их статус открыт для всех трёх линеек.

## Подготовка

1. Возьмите архив из артефакта CI `BobrovMenu-release`. Запишите версию и commit из
   `release-manifest.txt`, полную версию AutoCAD из `ABOUT`, язык, версию ACadSmartLeader и профиль.
2. Возьмите два тестовых профиля на каждую линейку. Для чистого профиля установите
   ACadSmartLeader 0.1.4+ и архив меню. Для обновления сначала запустите AutoCAD с ACadSmartLeader
   0.1.3, убедитесь в наличии группы `ACADSMARTLEADER` в `CUILOAD` и закройте AutoCAD. Обновите
   плагин до 0.1.4+, сохраняя профиль, затем установите проверяемый архив меню.
3. Включите `LOGFILEMODE=1` и запишите путь к журналу в `LOGFILENAME` для каждого DWG. Для проверки
   сквозного редактирования установите acadPaletteSetXDATA. В двух новых DWG запустите
   `_SL_DEMO` и `_.ZOOM` → `_Extents`, чтобы получить цели с демонстрационными данными.

## Проверки в AutoCAD

| ТЗ | Сценарий и ожидаемый результат |
| --- | --- |
| 2 | Запустите AutoCAD до открытия DWG, затем откройте первый тестовый чертёж. В чистом и обновлённом профиле проверьте одну вкладку **ACadSmartLeader**, одну панель **Умные выноски** и один контекстный пункт на умной выноске. В `CUILOAD` проверьте снятие `ACADSMARTLEADER` и наличие прежних групп. Повторите после перезапуска, смены рабочего пространства и переустановки архива. |
| 2 | Выполните `_SL_MENU_UNLOAD`. В текущем сеансе проверьте отсутствие вкладки и контекстного пункта. Запустите `_SL_CREATE`, `_SL_CREATE_GROUP`, `_SL_UPDATE` и `_SL_RULES` из командной строки. Выполните `_SL_MENU_LOAD` дважды, затем подтвердите одну регистрацию каждого элемента. |
| 3 | Переключайтесь между двумя DWG и в каждом нажмите все четыре кнопки. **Правила** открывает правила именно активного DWG. **Создать** спрашивает точку стрелки и место полки, ключ `_Rule` доступен. Выберите правило `CABLE` и создайте выноску на кабеле. **Создать групповую** на том же кабеле создаёт отдельную выноску по `CABLE_GROUP`. Через палитру XDATA измените `Cable_Mark` и `GC_HDGroup` на кабеле. После обновления обычная выноска показывает новую марку и группу, групповая — новую группу. |
| 4 | Включите `PICKFIRST=1`. После изменения данных кабеля выделите только созданную обычную выноску. Нажмите **Обновить** на ленте и примите область по умолчанию клавишей Enter. Проверьте, что изменилась только выделенная выноска. Выделите групповую и повторите через **Обновить умные выноски**. В обоих запусках проверьте доступность `_All`, `_Select` и `_Force`. |
| 4 | Создайте обычную мультивыноску через `_.MLEADER` в том же DWG. Выделите только её и проверьте отсутствие пункта **Обновить умные выноски**. Начните `_.LINE`, нажмите **Обновить** на ленте и проверьте сообщение об отказе и сохранение запроса точки линии. После выхода из `LINE` запустите обновление повторно. |
| 5 | Сохраните снимок вкладки и панели, снимок контекстного меню умной выноски и снимок обычной мультивыноски для сравнения. Приложите журнал для каждого проверенного DWG, полную версию AutoCAD, профиль и SHA сборки. Снимки сохраняйте в `docs/screenshots/` и связывайте с результатом в PR. |
