# BobrovMenu — установка меню Bobrov и ACadSmartLeader

Архив `BobrovMenu-manual-install-v<версия>.zip` добавляет в AutoCAD 2020–2024 x64 кнопку
**«Палитра XDATA»**:

- в строке меню — выпадающее меню **Bobrov** → **Палитра XDATA**;
- на ленте — вкладка **Bobrov** → панель **Палитра XDATA** → большая кнопка **Палитра XDATA**
  с подсказкой «Показать или скрыть панель «Свойства XDATA» (XDATAPALETTE)».

Кнопка — переключатель: каждое нажатие вызывает команду `XDATAPALETTE` плагина
[acadPaletteSetXDATA](https://github.com/veb86/acadPaletteSetXDATA), которая показывает или
скрывает палитру «Свойства XDATA». **Плагин устанавливается отдельно**; без него AutoCAD
сообщит о неизвестной команде `XDATAPALETTE`.

В AutoCAD 2020, 2021–2024 и 2025+ x64 архив также добавляет вкладку **ACadSmartLeader** с панелью
**Умные выноски** и пункт **Обновить умные выноски** в контекстном меню выбранной умной выноски.
Установите [ACadSmartLeader 0.1.4 или новее](https://github.com/veb86/ACadSmartLeader/releases)
отдельно. При обновлении с 0.1.3 сначала замените пакет выносок, затем установите этот архив.

Установка не требует прав администратора: все файлы размещаются только в профиле текущего
пользователя (`C:\Users\<имя>\AppData\Roaming`, он же `%APPDATA%`). AutoCAD загружает частичный
файл `BobrovMenu.cuix` для палитры XDATA и выбирает DLL интерфейса выносок по своей версии.

## 1. Распаковка

1. Закройте AutoCAD.
2. Windows может пометить скачанные файлы как полученные из интернета. Перед распаковкой
   откройте свойства ZIP-архива и установите флажок **«Разблокировать»** (`install.cmd`
   дополнительно снимает эту отметку).
3. Распакуйте архив в любую временную папку.

## 2. Копирование файлов в профиль пользователя

**Вариант А — автоматически.** Запустите `install.cmd` двойным щелчком (права администратора
не нужны). Скрипт скопирует папку `BobrovMenu.bundle` в `%APPDATA%\Autodesk\ApplicationPlugins`
и заменит предыдущую версию. Другие пакеты в этой папке (в том числе `acadPaletteSetXDATA.bundle`)
не затрагиваются.

**Вариант Б — вручную.**

1. Нажмите `Win+R`, введите `%USERPROFILE%` и нажмите Enter — откроется `C:\Users\<имя>`.
2. Скопируйте туда папку `AppData` из архива и подтвердите слияние папок.

После копирования должны существовать файлы:

```text
%APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle\PackageContents.xml
%APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle\Contents\BobrovMenu.cuix
```

## 3. AutoCAD

AutoCAD автоматически загружает пакеты из папки `%APPDATA%\Autodesk\ApplicationPlugins`.

1. Запустите AutoCAD и откройте DWG. Вкладка **ACadSmartLeader** появится на ленте.
2. В AutoCAD 2020–2024 на ленте также появится вкладка **Bobrov** с панелью **Палитра XDATA**.
3. Строка меню в AutoCAD 2021+ по умолчанию скрыта. Чтобы увидеть меню **Bobrov**, включите её
   сами: системная переменная `MENUBAR` = `1` (модуль эту переменную не меняет).
4. Нажмите **Палитра XDATA** — панель «Свойства XDATA» откроется; повторное нажатие скрывает её.

Кнопка запускает макрос `$M=$(if,$(getvar,cmdactive),^C^C)_XDATAPALETTE `: активная команда
отменяется, а без активной команды текущий выбор объектов сохраняется и отображается в палитре.
Глобальное имя `_XDATAPALETTE` работает в русской и английской версиях AutoCAD.

Для выносок выберите **ACadSmartLeader** → **Умные выноски**. При занятой командной строке
завершите текущую команду перед повторным нажатием. Для временного снятия меню выносок выполните
`SL_MENU_UNLOAD`, для восстановления — `SL_MENU_LOAD`. Команды выносок доступны из командной строки.

### Если меню или вкладка не появились

1. Выполните команду `CUILOAD` (или `MENULOAD`): в списке загруженных групп должна быть группа
   `BOBROVMENU`. Если её нет, проверьте пути из шага 2 и наличие `PackageContents.xml`.
2. Вкладка добавляется в рабочие пространства автоматически (`DefaultDisplay="AddToWorkspace"`).
   Если в своём рабочем пространстве вы её скрыли, включите её снова: правый щелчок на ленте →
   «Показать вкладки» → **Bobrov**, или в редакторе `CUI` перетащите вкладку **Bobrov** из
   группы `BOBROVMENU` в рабочее пространство.
3. Если в рабочем пространстве меню **Bobrov** не отображается в строке меню, добавьте его так
   же через редактор `CUI` (рабочее пространство → «Меню»). Модуль сам рабочие пространства не
   меняет.

## 4. Обновление

1. Закройте AutoCAD.
2. Распакуйте новую версию архива и запустите `install.cmd` (или повторите шаг 2 с заменой файлов).

## 5. Удаление

1. Закройте AutoCAD.
2. Запустите `uninstall.cmd` или удалите вручную папку:

   ```text
   %APPDATA%\Autodesk\ApplicationPlugins\BobrovMenu.bundle
   ```

При следующем запуске AutoCAD элементы меню пропадут. Установленные отдельно плагины
acadPaletteSetXDATA и ACadSmartLeader продолжают предоставлять свои команды.
